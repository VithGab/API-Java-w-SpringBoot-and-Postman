# API - Subscriptions Register

API REST developed in a simple sistem which allows register and consult yours subscriptions, taking into consideration the layered architecture: 

`Controler` -> `Service` -> `Repository`

### Technologies used:
* **Java 21**
* **Spring Boot 4.1.0**
* **Maven**
* **Postman**

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/SEU-USUARIO/demo-subs.git
   ```

2. Enter the project folder:
   ```bash
   cd demo-subs
   ```

3. Run the application using the Maven Wrapper:
   * **Windows (PowerShell):**
     ```powershell
     .\mvnw.cmd spring-boot:run
     ```
   * **Linux/Mac:**
     ```bash
     ./mvnw spring-boot:run
     ```

The application will start at `http://localhost:8080`.

---

## Endpoints

### Register a subscription
`POST /subscription`

**Request Body (JSON):**
```json
{
  "name": "Netflix",
  "category": "streaming",
  "price": 39.90,
  "paymentDate": 10
}
```
*Note: The `id` field is automatically generated by the system if not provided.*

### Find a subscription by ID
`GET /subscription/{id}`

*Example:* `GET /subscription/1`

## Project Structure

```text
src/main/java/Subscription/demo_subs/
├── model/         (Subscription class)
├── repository/    (in-memory storage using a list)
├── service/       (business logic)
└── controller/    (handles HTTP requests)
```

The data flow follows: **Controller** ➡️ **Service** ➡️ **Repository**. No database is used (data is stored in memory while the application is running).
